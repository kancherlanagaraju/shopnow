================================================================================
DEMO TALKING POINTS
================================================================================

ARCHITECTURE:
  • LangGraph for deterministic routing (not prompt chaining)
  • Explicit rules for sentiment and department classification
  • Structured outputs (Pydantic) for reliable LLM responses

RAG GROUNDING:
  • System refuses to generate without sufficient context
  • Controlled abstention prevents hallucinations
  • Relevance threshold (0.35) prevents low-confidence answers

COST OPTIMIZATION:
  • Local Hugging Face embeddings = $0 API cost
  • Groq LLM on free tier = minimal cost
  • Cost per query: ~$0.001

SAFETY & DETERMINISM:
  • 5/5 evaluation tests passing
  • Deterministic tests (not LLM judges)
  • Reproducible behavior
